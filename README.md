# WP Cross-Site Sync

WordPress-плагин для синхронизации контента, ACF-полей, опций и меню между двумя сайтами.

## Возможности

- Синхронизация страниц, записей, кастомных типов
- Синхронизация ACF-полей и групп
- Синхронизация меню и опций
- Синхронизация терминов таксономий
- Гибкая настройка исключений: страницы, опции, меню, мета, ACF-группы, термины
- Два режима: **source** (источник) и **receiver** (приёмник)
- Аутентификация через Application Password или секретный ключ
- Автоматическая синхронизация через WP-Cron: контент 2 раза в день, медиа — каждый час
- Ручной запуск синхронизации из админки
- Логирование операций

## Стек

- PHP 8+
- WordPress
- REST API
- WP-Cron
- Application Password
- ACF
